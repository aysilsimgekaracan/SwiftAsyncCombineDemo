# SwiftAsyncCombineDemo

A practical demo project to learn modern Swift concurrency and Combine framework.

- **async/await**
- **Combine**
- **SwiftUI** with MVVM architecture
- Real-time search with **debouncing**

## 🔗 API

Uses [JSONPlaceholder](https://jsonplaceholder.typicode.com) - Free fake API for testing
